# UI 改进设计规格

**日期**: 2026-07-04  
**状态**: ✅ 已完成

## 概述

优化 MotionSlice 视频切片工具的用户界面体验，解决四个核心问题：
1. 全局滚动条样式优化
2. 批量视频列表路径显示
3. 导出路径层级保留
4. 导出队列路径显示与布局优化

---

## 问题 1：滚动条样式优化

### 问题描述
- 原生滚动条样式不统一，与系统风格不符
- 在深色主题下视觉不协调

### 解决方案
**全局滚动条样式定制**（`src/styles/global.css`）：
- 宽度：6px（细窄、浮动式）
- 轨道：透明（不显示）
- 滑块：半透明白色、圆角 3px
- 悬停：增强不透明度

**实现细节**：
```css
::-webkit-scrollbar { width: 6px; }
::-webkit-scrollbar-track { background: transparent; }
::-webkit-scrollbar-thumb {
  background: rgba(255, 255, 255, 0.3);
  border-radius: 3px;
  opacity: 0.6;
}
::-webkit-scrollbar-thumb:hover {
  background: rgba(255, 255, 255, 0.5);
  opacity: 1;
}
```

## 问题 2：批量视频列表路径显示

### 问题描述
- 文件名相同时无法区分来源
- 缺少父目录路径信息

### 解决方案
**在文件名后显示父目录路径**：
- 格式：`文件名.mp4 📁 根目录/子目录/.../文件所在目录/`
- 路径从用户勾选的根目录开始显示完整相对路径
- 路径过长时智能压缩为 `根目录/首层/.../末层/`
- 最大长度：80 字符（中间面板空间充裕）
- CSS 最大宽度：500px，超出显示省略号
- 鼠标悬停显示完整绝对路径

**实现细节**：
1. 创建 `src/utils/pathFormat.ts` 工具模块
2. 实现 `formatPathFromRoot()` 函数
3. 在 `BatchVideoGrid.vue` 模板中添加路径显示
4. 样式：等宽字体、灰色、11px、80% 不透明度

## 问题 3：导出路径层级保留

### 问题描述
- 导出时文件被平铺到目标目录，丢失原有层级结构
- 例如：`项目1/素材/文件.mov` 导出后变成 `Downloads/文件.mov`

### 解决方案
**保留从根目录开始的完整相对路径**：
- 导出路径：`输出目录/根目录/子目录.../文件名`
- 例如：`Downloads/项目1/素材/文件.mov`
- 自动创建多层目录结构

**实现细节**：
1. 修改 `ExportHandler.ts` 的导出逻辑
2. 使用 `payload.rootDir` 计算相对路径
3. 使用 `path.join()` 拼接完整输出路径
4. 使用 `fs.mkdirSync(recursive: true)` 创建目录

## 问题 4：导出队列路径显示与布局优化

### 问题描述
- 导出队列中文件名相同时无法区分
- 队列高度不固定，按钮可能被遮挡
- 路径超出容器时没有省略号
- 路径右侧紧贴滚动条，缺少边距

### 解决方案

#### 4.1 路径显示
**换行显示路径信息**：
- 第一行：`文件名 - 切片标签` + 状态
- 第二行：`📁 根目录/子目录/.../文件所在目录/`
- 路径使用与批量视频列表相同的 `formatPathFromRoot()` 函数
- 最大长度：35 字符（右侧空间较窄）
- 末层目录名最多显示 12 个字符，超出截断

#### 4.2 布局优化
**固定高度队列**：
- 队列高度：400px（固定）
- 只有垂直滚动条
- 固定区域添加 `flex-shrink: 0`：
  - `.queue-summary`（任务摘要）
  - `.output-dir-selector`（输出目录）
  - `.queue-progress`（进度条）
  - `.export-actions`（按钮区域）

#### 4.3 样式优化
**路径显示样式**：
```css
.task-path-line {
  width: 100%;
  overflow: hidden;
  padding-right: var(--vt-space-2);
  display: block;
}

.task-parent-path {
  max-width: 100%;
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
  display: inline-block;
}
```

**效果**：
- 路径超出时显示省略号
- 右侧有适当边距，不紧贴滚动条
- 鼠标悬停显示完整路径

## 统一路径显示逻辑

### 核心函数：`formatPathFromRoot()`

**位置**：`src/utils/pathFormat.ts`

**功能**：
- 从根目录开始显示完整相对路径
- 智能压缩超长路径
- 处理多种路径层级场景

**压缩规则**：
1. **单层子目录**：截断目录名 + `...`
2. **两层子目录**：保留首层，截断末层
3. **多层子目录**：`根目录/首层/.../末层/`
4. **末层目录名**：最多 12 字符，超出截断

**使用场景**：
- 批量视频列表：`maxLength = 80`
- 导出队列：`maxLength = 35`

- `ExportHandler.ts` 使用 Node.js 的 `path` 和 `fs` 模块
- 所有组件使用 `useVideoStore.inferRootDir()` 获取根目录
